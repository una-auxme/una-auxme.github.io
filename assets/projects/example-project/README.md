# Example Project Assets

Place your project-specific assets in this folder:

## Suggested Files

- `hero-image.png` - Main hero image or screenshot (1200-1600px wide)
- `results-comparison.png` - Quantitative results figure
- `ablation-study.png` - Ablation study results
- `architecture-diagram.png` - System architecture or method diagram
- `demo-screenshot-1.png` - Additional demonstration images
- `demo-screenshot-2.png`

## Notes

- Images should be optimized for web (compressed, appropriate format)
- Use descriptive filenames
- Keep individual file sizes under 500KB when possible
- For videos, use YouTube/Vimeo embeds instead of storing video files
